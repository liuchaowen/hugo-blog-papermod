今天在 GitHub Trending 上看到一个有意思的项目：**狗头军师（Goutoujunshi）**，一个把情绪支持、关系科学与可执行策略整合进 AI 的恋爱军师，支持聊天截图分析、MBTI 关系判断、跨周期策略与本地记忆。

## 一、项目概述

狗头军师的核心定位是「先接住情绪，再给策略」，不只输出话术，而是一套覆盖恋爱全周期的 Codex Skill。它能读取聊天截图、导出文本和用户转述，区分素材来源与事实边界；也能把分析落到一句可发送的话、一次具体邀约、第一次见面安排或一段可复盘的对话演练。

### 核心特性一览

| 功能 | 说明 |
|---|---|
| 情绪承接 | 先接住用户情绪，再分析事实与推测 |
| 聊天截图分析 | 锁定说话人，区分事实/推测/未知 |
| MBTI & 人格判断 | 结合行为、MBTI、评分给明确判断 |
| 具体行动方案 | 可发送的话术、邀约时机、观察窗口 |
| 长期记忆 | 同意后跨任务记住双方档案 |
| 多元关系支持 | 覆盖异性/同性/双性/跨性别等多元身份 |

### 项目结构

```
goutoujunshi/
├── SKILL.md                    # 核心行为与工作流
├── agents/openai.yaml         # Codex 展示与默认提示词
├── references/
│   ├── knowledge/             # 关系科学与跨学科知识文档
│   └── practical/             # 沟通、工具适配与记忆规则
├── documentation/             # 架构、流程与安全边界
└── scripts/
    ├── validate_skill.py      # 项目完整性检查
    └── memory_store.py        # 同意门禁、限量记忆、撤销与删除
```

## 二、技术原理

### 知识库分层设计

项目将核心关系知识、实用沟通和工具适配分开维护，并按当前问题只加载必要资料——实测日常上下文成本降低约 48.3%。知识库涵盖以下跨学科领域：

**关系心理学层**：吸引与选择、伴侣回应性、社会交换、比较水平（CL）、替代选择、承诺与依赖机制。

**人格与情绪层**：MBTI 的合理用法与局限、Big Five、依恋风格、焦虑型与回避型依恋的识别与应对。

**沟通策略层**：三层话术编排（情绪承接 → 策略建议 → 话术输出）、对话演练、倾听共情与冲突处理。

**风险与边界层**：PUA 机制识别与低风险替代方案、煤气灯等操控手段的识别与拒绝策略。

### 分析流程设计

典型回答的产生流程为：

```
用户叙述
  → 情绪落地（先接住情绪）
  → 建立本人及目标对象档案
  → 分离事实／推测／未知
  → 检索当前情境所需知识（只加载 1–3 份资料）
  → 比较互惠、现实、风险与机会成本
  → 给出明确首选建议和理由
  → 生成行动、话术、观察窗口与停止条件
```

### 安全边界机制

项目内置明确的安全边界——暴力、胁迫、跟踪、诈骗和自伤风险不通过普通恋爱话术处理，而是触发危机转介流程，不「帮用户破解」对方的明确拒绝。

## 三、安装与快速开始

### 环境要求

- [Codex](https://github.com/openai/codex) 或支持自定义 Skill 的 AI 助手
- 可选：ChatLab（用于聊天截图和导出文件分析）

### 安装步骤

将仓库克隆到 Codex 的 Skills 目录：

```bash
git clone https://github.com/powerycy/goutoujunshi.git ~/.codex/skills/goutoujunshi
```

### 快速启动

在支持 Codex 的界面输入：

```
使用 $goutoujunshi 帮我梳理情绪、分析当前关系，并给出下一步建议。
```

首次使用需要提供：

```text
你：MBTI / 综合评分0–100 / 主要优势和短板
对象A：代号 / MBTI / 综合评分0–100 / 当前关系
经过：认识方式、发展时间、关键事件、联系和投入情况
目标：推进、确认、修复、比较选择，还是退出
情绪：目前最难受的点、强度0–10
```

### 分析聊天截图（可选）

安装 ChatLab 后，直接说：

```text
使用 $goutoujunshi 通过 ChatLab 分析我和对象A最近三个月的聊天。
```

系统会先预览导入计划，再限定会话、对象和时间范围查询。不会直接读取或解密聊天软件数据库。

## 四、使用方法与实战

### 场景一：不知道这句话怎么回

输入：对方发了一条模糊的消息，不知道怎么接。

狗头军师会先给一条**可直接发送**的首选话术，再补上时机判断和后续分支路径。

### 场景二：想追求、复联或推进关系

输入：刚认识一个月，想约对方出来但不知道怎么开口。

系统会给出具体邀约方案，并说明为什么这个时机/措辞更合适，以及如果对方不积极回应时的备选方案和观察窗口。

### 场景三：看不懂对方行为，在多人之间犹豫

输入：在两个相亲对象之间犹豫。

狗头军师会结合行为数据、MBTI 参考、主观评分和现实条件，给出结构化比较，而非「凭感觉选」。

### 场景四：聊天太长、截图太多

直接粘贴或上传，系统会自动锁定双方说话人，区分事实（原文确认）、推测（基于上下文推断）和未知（无法确认），避免把推测写成事实。

## 五、常见问题与解决方案

**Q: 狗头军师是 PUA 工具吗？**
不是。项目明确禁止用策略绕过对方的明确拒绝。所有策略都附有适用条件与长期成本说明，风险与低风险替代方案并列呈现。

**Q: MBTI 结果是决定性的吗？**
不是。MBTI 帮助提问和生成方案，但不会被包装成诊断、命运或「必胜公式」。判断依据始终是具体的人、具体行为、双方意愿和现实条件。

**Q: 长期记忆会保存我的聊天记录吗？**
不会。记忆只保存精简档案（代号、关系阶段、关键进展），不保存完整聊天记录，且需用户明确同意，可随时查看、暂停或清空。

**Q: 支持哪些性取向和关系形态？**
覆盖异性恋、男同性恋、女同性恋、双性恋、泛性恋、无性恋等，也支持单身约会、长期伴侣、婚姻、异地、再婚、跨文化关系，以及知情同意基础上的非单偶关系讨论。

## 六、总结

狗头军师最有价值的地方在于它不只给答案，而是**先接住情绪，再拆解事实与推测，最后给出可执行的下一步**。对于在感情中常常内耗、不知道怎么处理复杂局面的人来说，这套基于跨学科知识库的 AI 顾问提供了一个结构化的思考框架。如果你在关系里需要清醒和可操作的建议，这个开源项目值得一试。
